# Publishing checklist

Recommended repository name:

`forge-gpu-weights-per-preset`

## First GitHub release

1. Create a new empty GitHub repository.
2. Upload all files from this folder to the repository root.
3. Before publishing, replace `YOUR_USERNAME` in `README.md` with your GitHub username.
4. Suggested repository description:

   `Per-preset GPU Weights (MB) control for Stable Diffusion WebUI Forge Neo.`

5. Suggested topics:

   `stable-diffusion`, `forge`, `forge-neo`, `stable-diffusion-webui`, `extension`, `gpu`, `vram`

6. Create release/tag:

   `v1.0.0`

7. Suggested release title:

   `Forge GPU Weights per Preset v1.0.0`

## Suggested release notes

Restores the old-style GPU Weights (MB) control in Forge Neo and stores a separate GPU allocation for each UI Preset. The extension does not modify Forge core files.
